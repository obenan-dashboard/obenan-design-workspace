# Start Here

This is the portable Obenan design workspace for Ceren and any Claude, Codex,
Figma, or human contributor working on customer-visible Obenan design.

It contains the actual Markdown design sources, original old-logo variants,
and both brand guideline PDFs. The separately delivered FULL archive adds the
complete 382-file Gleb branding and motion library. This is design context, not
a production codebase and not authority to publish, merge, or deploy.

## Mandatory reading order

Read these files before planning or changing anything:

1. `START_HERE.md`
2. `AGENTS.md`
3. `STATUS.md`
4. `DOMAIN.md`
5. `reference/design-principles/DESIGN_PRINCIPLES_2026.md`
6. `reference/design-principles/BRAND_SYSTEM.md`
7. `reference/design-principles/BRAND_ASSET_LIBRARY.md`
8. `reference/design-principles/BRAND_EMOTION_WEBSITE_SPEC_2026-08-13.md`
9. `reference/design-principles/FACTORY_GIRL_ASSET_REGISTER_2026-08-13.md`

Inspect the task-relevant quick-start assets here. For motion, After Effects,
UI-package, social, and deeper original sources, use the FULL archive.

## Current design hierarchy

- Identity: approved brand book and original/canonical logo assets.
- Product UI: `DESIGN_PRINCIPLES_2026.md`.
- Website system: `BRAND_SYSTEM.md`.
- Website emotion and imagery: the dated brand-emotion specification.
- Hospitality imagery: the Factory Girl register and its approval gates.
- Current implementation truth: the current production codebase and release
  evidence, which are intentionally not bundled here.

Exploratory frames, legacy assets, local branches, agent output, and previews
are not canonical by themselves.
