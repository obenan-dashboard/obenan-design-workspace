# Proposed design knowledge

Everything in this directory is a proposal for review. It is not reusable
design authority until Seven explicitly approves it and a curator records the
decision and provenance. Read `DESIGN_CORE_v1.md` first, then
`APPLIED_DESIGN_GUIDE_v1.md` for the surface you touch, then
`TOKEN_COMPONENT_CONTRACT_v1.md` for exact names; `DECISION_REQUESTS_v1.md`
lists what remains open.
