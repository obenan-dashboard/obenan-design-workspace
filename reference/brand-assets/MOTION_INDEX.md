## Agent retrieval rule

1. Read `START_HERE.md`, `AGENTS.md`, `STATUS.md`, and `LIBRARY_MAP.md`.
2. Open this index, then inspect the actual candidate files before choosing.
3. Report the exact repository-relative asset path used.
4. Reuse approved assets; never infer approval from file availability.
5. For customer-visible implementation, re-prove current identity approval,
   source provenance, accessibility, performance, and production authority.
