# Original Gleb branding assets

This is a byte-preserving mirror of Seven's original `Gleb` source folder,
excluding only 20 macOS `.DS_Store` metadata files. Its 350 material files
include MP4/MOV video, After Effects projects, JSON logo animations, ZIP
project packages, PNG images, PDFs, and text notes. Folder names and filenames
are preserved. Large media and project archives use Git LFS; install Git LFS
before cloning if you need the actual binaries instead of pointer files.

Useful starting points:

- [Logo intro and loop JSON](Gleb/Logo_Animation_asset/)
- [Rendered logo and motion loops](Gleb/Gleb%20New%20Animated%20Assets/)
- [Video and web-submit animations](Gleb/Animations%20Jesh%20for%20WebSubmit/)
- [Social video sources](Gleb/Social/)
- [UI animations](Gleb/UI%20animations/)

The files are source and history, not a declaration that a particular logo,
lower third, transition, claim, or visual treatment is approved for new use.
Do not redraw the logo; obtain the relevant current brand decision before
publishing a new customer-visible asset.
